## 1. 오너 결정

오너의 말은 옮기지 않고 뜻만 적는다.

- 2026-11-26 오너가 시스템 테마를 따르며 워드마크 드로잉 → 로고 상승 → 로딩 스피너 → 3초 유지 → 부드러운 페이드아웃(`0.9s cubic-bezier(0.65, 0, 0.35, 1)`) → 빈 화면 후 재등장을 반복하는 단독 로딩 화면을 검토한 뒤, 이를 `/designsystem`의 `Loading states` 아래에 별도 버튼 없이 클릭 가능한 프리뷰 카드로 배치하고 클릭 시 `/designsystem/loading` 전체 화면으로 열리도록 정했다.
- `/designsystem/loading`은 검색 비노출(`noindex, nofollow`)이며 URL만 공유해도 바로 전체 화면 로딩 스크린을 볼 수 있고, 우연히 들어간 사용자가 갇히지 않도록 화면 아무 곳이나 클릭하면 다시 `/designsystem`으로 돌아가도록 정했다.
- 이번 열차는 범위가 좁은 디자인 시스템·UI 프리뷰 추가이므로 바로 `9.0.844 / v844`로 배포하고 배포 기록 PR까지 마무리하되, 배포 뒤 수동 Full E2E는 돌리지 않기로 정했다.

## 3. 사용자에게 바뀌는 것 [화면 바뀜]

1. **`/designsystem`의 `Loading states` 부트 스플래시 프리뷰**: 기존 스피너·헤더 로딩 데모 바로 아래에 버튼이나 텍스트 장식 없이 실제 부트 스플래시 반복 프리뷰 카드(`.boot-splash-demo`)가 표시되며, 카드를 클릭하면 `/designsystem/loading` 전체 화면으로 이동한다. 뷰포트 밖에서는 일시 정지되고 스크롤해 들어오면 처음부터 재생된다.
2. **`/designsystem/loading` 전체 화면 로딩 프리뷰**: URL만으로 바로 열 수 있는 순수 전체 화면 로딩 스크린(`noindex, nofollow`, 시스템 다크 `#121212` / 라이트 `#f8f9fa` 자동 추종). 워드마크 드로잉 → `1.2s cubic-bezier(0.8, 0, 0.2, 1)` 상승 + `0.35s ease-out 0.6s` 스피너 → 3초 유지 → `0.9s cubic-bezier(0.65, 0, 0.35, 1)` 페이드아웃 → 빈 화면 후 재등장을 반복하며, 화면 아무 곳이나 클릭하거나 `Escape`를 누르면 `/designsystem`으로 돌아간다(`/designsystem`에서 진입한 경우 `history.back()`으로 스크롤 위치 유지). `prefers-reduced-motion: reduce`에서는 정적인 완료 워드마크와 정지 스피너를 표시한다.
