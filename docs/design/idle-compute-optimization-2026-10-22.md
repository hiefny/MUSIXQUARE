## 왜 고쳤나

갤럭시 S25 Chrome에서 무선 이어폰으로 들을 때, 리버브를 켜면 불규칙한 팝이 난다는
제보가 있었다. 오너는 Pixel 에뮬레이터에서 음악을 백그라운드로 보냈을 때 같은 소리를
재현했다. Chrome 153(2026-09-08 안정판)부터 ConvolverNode의 백그라운드 스레드가
없어지고 모든 단계가 오디오 스레드에서 돈다(Chromium 커밋 `9749ea76`). 그런데 앱은
효과를 꺼도 리버브·가상 저음·익사이터를 늘 연결해 두고 계산했다. 원인을 실기기에서
확정하지는 못했다. 그래서 이번에는 꺼져 있거나 필요 없을 때 도는 계산을 전수 조사했다.
찾은 항목은 독립 검증자 세 명이 반박을 시도해 확인했다. 그다음 UI/UX를 바꾸지 않는 범위로
좁혀 고쳤다.

Chromium 153 오프라인 렌더로 잰 데스크톱 코어 한 개 기준 점유율(20초 렌더)은 다음과 같다.

| --------------------------------------- | ------------------: |
| 원음만                                  |                0.0% |
| 리버브 믹스 0                           |                7.3% |
| 같은 리버브, 입력만 끊음                |                0.1% |
| 가상 저음 0                             |                1.9% |

| 리버브 0.25초 / 1초 / 10초+1초          | 0.6% / 1.2% / 15.4% |

휴대폰은 코어가 더 느리고 백그라운드에서 우선순위도 낮다. 이 표는 데스크톱 측정값이며
실기기 값이 아니다.

## 바뀐 것

### 오디오 스레드

- **리버브**:
  - 믹스가 0이 되고 크로스페이드 램프가 끝나면(실제 gain 값으로 판정) 입력만 끊는다.
    출력은 연결된 채 두어 꼬리가 무음으로 비고 Chromium이 노드를 쉬게 한다.
  - 잔향은 처음 켤 때 만들고, 반사 시간을 바꾸면 그때 다시 만든다. Off 프리셋과
    데모 토글은 믹스 0에서 잔향을 다시 만들지 않는다.
  - 반사 지연은 잔향 안의 앞 무음이 아니라 별도 DelayNode다. 그래서 반사 지연을
    바꿔도 잔향을 다시 만들지 않는다. Chrome 정규화가 그 무음을 평균에 넣던 편차도
    사라졌다(반사 시간 0.2초·반사 지연 1초에서 +7.8 dB였고, 프리셋은 약 0.1 dB).
  - 오너 결정대로 크로스페이드나 두 번째 컨볼버는 넣지 않았다. 켜거나 반사 시간을
    바꿀 때 리버브만 잠깐 비는 것은 허용한다.
- **가상 저음·익사이터**: 목표 gain이 0이면(우퍼 역할 포함) 램프 뒤 입력을 끊는다.
  가상 저음은 다시 연결한 뒤 20 ms 뒤에 램프를 시작해, 필터와 압축기가 켜지는 순간을
  가린다. 익사이터 주석의 "CPU 절약"은 이제 사실이 됐다.
- **시스템 오디오 공유자**: 캡처를 효과 체인에 넣지 않고, 0.5 이득으로 분석 노드에만
  보낸다. 비주얼라이저는 그대로 움직인다(오너 요구). 효과 체인은 입력이 없어 비고 쉰다.
- **모노·5.1**: 위드너 입력을 명시적 2채널 `speakers`로 바꿨다.
  - 모노 파일이 왼쪽에서만 나오던 문제와 오른쪽 역할에서 무음이던 문제를 고쳤다.
  - 5.1 파일의 가운데·서라운드는 표준 다운믹스로 들어온다. LFE는 여전히 빠진다.
  - 서라운드 경로의 `FilePlaybackRoute.input`은 discrete로 그대로 둔다.
- **큰 파일 엔진**: 붙어 있는 같은 형식의 디코딩 조각을 0.25–0.5초 버퍼로 묶어 예약한다.
  - 정상 재생 중 대기 재생 노드는 306–750개에서 약 32개가 됐다.
  - 시작·탐색 뒤 첫 1초는 묶지 않아 시작 지연이 그대로다.
  - 패리티 e2e의 지연·최대 오차는 기준과 같고, RMS 차이는 약 1e-9 이하다.

### 메인 스레드·화면

- **탐색 막대**: 0.1초 단위 값이 바뀔 때만 쓴다. 플레이 탭이 가려졌거나, 페이지가
  숨었거나, 화면 보호기가 덮으면 프레임 루프를 멈춘다. 탭 전환·덮개 해제 때는
  동기로 다시 그려 View Transition에 낡은 값이 찍히지 않는다. 250 ms 곡 끝 확인은 유지한다.
- **YouTube 시간 표시**: 실제 DOM 값과 비교해 달라진 값만 쓴다.
- **초대 QR 스피너**: 숨김 전환이 끝나면 애니메이션을 일시정지한다.
  display:none을 쓰지 않아 0.18초 페이드와 이어 돌기는 그대로다.
- **재생 화면 제목 흐름**: 화면 보호기가 덮은 뒤 CSS로 일시정지한다. 동작 줄이기에서는
  흐르지 않고 줄임표로 보인다(오너 결정, 재생목록과 같은 방식).
- **BOT 입력 중 말풍선**: 60초 TTL이 지나도록 결과가 없으면 기존 `chat.bot_failed`
  문구로 조용히 바꾼다. 알림·미리보기·안 읽음 수는 늘지 않는다.
  요청자의 BOT 세션이 대체될 때도 같다.
- **화면 보호기**:
  - 그리지 않는 시계 캔버스를 매 프레임 지우던 일과, 매 프레임 만들던 문자열·WeakMap을 없앴다.
  - 입자는 60 Hz 기준 시간으로 움직인다(오너 결정). 120 Hz 화면에서 2배 빨라지지 않고,
    프레임 상한은 두지 않았다.
  - 다음 분의 숫자를 55–59초에 미리 만든다(오너 결정). 분이 바뀌는 프레임이
    1280×720@1에서 93–213 ms에서 1.2–2.5 ms로, 1920×1080@2에서 0.85–1.56 s에서 2.3–4.7 ms로 줄었다.
  - 크기 변경은 150 ms 멈춘 뒤 한 번만 다시 만든다.
  - 동작 줄이기에서는 입자가 멈춘다.
  - 결정적 비교 스크린샷에서 시계는 픽셀까지 같다.
- **기타**: 쓰지 않는 `.graphic-line-active` 애니메이션을 지웠다. 소개 페이지 시계는
  화면 밖에서 멈춘다.

### 타이머·네트워크

- **YouTube**:
  - 화면 루프는 페이지가 숨었고 일시정지(또는 자동재생 의도 없는 CUED/UNSTARTED)일 때만
    2초로 늦춘다. 그 밖에는 500 ms를 그대로 둔다. 충돌 감지는 시간 기준(2,250 ms)으로 바꿨다.
  - `getVideoData`는 틱마다 한 번 읽어 나눠 쓴다.
  - 게스트는 이미 ENDED·CUED일 때 `stopVideo`를 생략한다.
  - 게스트의 제목 수집은 방장 제목이 15초 동안 새로 오지 않을 때 빈 칸만 채운다.
    숨긴 페이지는 수집을 멈추되, 게스트가 있는 방장은 계속한다. 죽은 `fullFetch`도 지웠다.
  - 재합류 "busy"는 CUED·영상 불일치일 때 다음 방장 프레임에서 다시 시도한다.
- **PRO**:
  - 하트비트 응답 두 형태에 시스템 오디오 상태를 싣는다. 60초 안전 GET, 만료 재확인,
    15초 무한 재시도를 없앴다. 입장 때와 실시간 무효화 때의 GET은 남긴다.
  - 같은 스냅샷이면 해석·비교 단계를 건너뛴다. 제어 채널 재구성, 부속 재시도,
    미디어 훅 복구는 그대로 돈다.
  - 효과 저장 재시도는 1·3·10·30·60초로 늘리고, 재연결·복귀 때 다시 시도한다.
  - SFU 재구독은 2.5초부터 30초까지 늘리고, 재연결 때 처음부터 다시 센다.
  - 공유가 끝난 뒤의 재생 복구는 숨김 동안 쉬었다가 복귀하면 다시 시도한다.
- **기타**:
  - 게스트 역할 배지는 지연 갱신 때 다시 그리지 않는다.
  - 활동 통계 표본은 조건이 맞을 때만 뜬다.
  - 방장 상태 확인은 숨김 동안 멈춘다.
  - 하트비트 감시는 게스트가 있는 Standard 방장만 돌린다.
  - 주 글꼴 재시도는 1초에서 300초까지 늘리고, 시도 시한은 8초에서 60초까지 늘린다.
  - 세션을 나가도 효과 입력 게이트 타이머는 남긴다.

### 통합 e2e

`a175cb92`의 `build:e2e`로 Chromium spec 55개를 돌렸다. 범위는 다음과 같다.

- CI의 critical·runtime 묶음
- 재생목록 전체(지연 로딩한 선택 컨트롤러 포함)
- 오디오 효과·채널·시스템 오디오
- 큰 파일·패리티
- PRO 입장·활성화
- 채팅·BOT·YouTube·탐색·데모·소개 페이지·시각화·연결·미리받기·RAM 조립
