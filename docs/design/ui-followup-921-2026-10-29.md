## 오너 지시와 결정

- **토스트 글자(2026-10-29 아침).** 9.0.20이 토스트 글자를 본문 400으로 내렸는데, 오너가 9.0.19의 이름표 600으로
  되돌리기로 했다. 크기, 색, 자리, 움직임은 그대로다(W1).
- **화면 보호기 트랙 제목(같은 아침).** 화면 보호기 페이지의 트랙 제목을 500 → 600으로 올리고 부제는 500 그대로
  둔다(W2).
- **잠깐 뜨는 글자 규칙(같은 아침).** 무언가 일어나서 나타났다가 저절로, 또는 그 순간이나 모드가 끝나면 사라지는
  글(토스트, 불러오기·기다리기 줄, 전체 화면 세션 안내, 진행·결과 줄, 흐린 패널 위 모드 안내)과 빨간 오류 줄은
  이름표 600이다. 화면을 열면 늘 있고 그대로 두면 남는 글(설명, 대화상자 본문, 힌트, 빈 목록 안내)은 본문 400이다.
  대화상자는 제목 700과 본문 400을 지키고, `/events` 페이지의 토스트와 안내 줄도 600으로 맞춘다(W3). 이 규칙을 따라
  `/events`의 쉬는 닉네임 힌트('12자 이내로 입력해 주세요.')는 본문 400으로 했다(W4, W3 검토가 물은 것).
- **칩 한 줄 계획(같은 아침).** 칩은 고른 700에서 한 줄에 들도록 문구를 줄이고 가드 시험으로 지킨다. 문구를
  줄여도 칸이 모자라면 그대로 받아들인다. 칩을 600 / 400 두 굵기로 하는 안은 검토 뒤 버렸다. 설정과 시작 화면의
  역할 칩은 데모의 짧은 역할 단어(왼쪽 / 오른쪽 / 저음 / 중앙)를 쓴다.

## 섞인 버전과 되돌리기

### 섞인 버전

- App 9.0.20과 9.0.21은 같은 방에서 함께 쓴다. 이 열차는 CSS, 화면 글자, 디자인시스템 문서, 계정 창의 DOM 표지
  하나(`data-account-waiting`, 그 기기 안에서만), 미디어 고르기 창의 로컬 포커스 조건 하나(A5)만 바꾸고 메시지,
  상태 모양, 저장 키, 저장 데이터는 그대로다.
- 역할 칩, 도움말 역할 이름, 채팅 역할 이름은 각 기기가 자기 언어로 그리므로 버전이 섞여도 다른 기기의 화면에 닿지
  않는다. 지운 `role.*` 키는 메시지에 실리지 않는다.
- Worker는 바뀌지 않는다(머리 표 Deploy target).

### 되돌리기

- 기본은 hotfix 절차대로 더 높은 SemVer와 캐시 epoch의 코드 되돌리기다.
- App만 9.0.20으로 되돌리면 굵기와 칩 문구가 9.0.20으로 돌아간다. 통신 모양과 저장 데이터가 같아 다른 Worker는
  그대로 둔다. 이 열차는 최소 앱 빌드, 계약 표지, forward floor, D1, 비밀, 바인딩, Wrangler 설정, CORS를 바꾸지
  않는다. 되돌릴 때의 바닥 판정은 그때의 `docs/release-record.md` §1을 따른다.

## 확인하지 않은 것

- 실기기와 iOS Safari: 모든 측정이 Windows의 Chromium과 WebKit이다. 위 WebKit 한계(대역 RTCPeerConnection, 옮겨 그린
  데모, 계산된 굵기만)도 있다.
- Linux: Linux 글꼴 에뮬레이션과 Linux Chromium(CI)의 글꼴 힌팅은 재지 않았다. 가드는 브라우저 없이 같은 글꼴
  파일로 재므로 CI에서도 같은 폭을 쓰지만, 화면에 그려진 폭은 다를 수 있다. 예외 14개는 4px 여유가 없다.
- E2E: 라운드 4와 5가 Chromium 후보 레인(19)과 critical 레인(98)을 돌렸고, 라운드 5가 A5의 WebKit 반복 실행과
  포인터 열기 E2E를 더했다. 바뀐 화면의 관련 E2E와 WebKit 레인 전체는 릴리스 준비에서 돈다.
- A5: 실제 기기(iOS Safari 포함)에서 키보드로 창을 열고 곧바로 Tab을 누르는 경쟁은 보지 않았다. 화면 낭독기가 창을
  열 때 읽는 첫 포커스도 듣지 않았다(포커스 대상은 바뀌지 않음).
- 조립 증분의 화면: 도움말 역할 이름(A1)과 터키어 4단계(A3)는 시험, 계산기, 영어 대체 글 검사로만 봤고 브라우저
  화면 비교는 하지 않았다.
- 화면 낭독기: ml·ta 언어 칩의 바뀐 이름(`settings.language_manual_aria`)을 실제 낭독기로 듣지 않았다.
- 원어민 검토: 152줄 모두와 A1의 도움말 역할 이름(오너 항목 3의 일곱이 우선).
- Chromium 79 TV: 정적 검사(`guard:legacy-tv-build`)뿐이다.
- 화면 보호기의 실제 Google Sans 600 면, 가드 밖의 선택 묶음(언어 목록, 대화상자 라디오), 한국어 밖의 `/events`.
- UI 키트 토스트는 개발 서버의 소스만 봤다(배포되지 않음).
- 배포 전이라 아직: 운영 화면, 업데이트 창, 관리자 Translations의 남은 제안 줄.
