Frequently Asked Questions

Last updated: July 16, 2026

1. Getting Started

What is MUSIXQUARE?
MUSIXQUARE is a web app that connects multiple devices like wireless speakers so you can play music, YouTube, and system audio together.
Do I need to install an app?
No. You can use MUSIXQUARE directly in a browser. If you use it often, installing it as a PWA on iOS, Android, Windows, or macOS can make it easier to open.
Is MUSIXQUARE free?
Yes. MUSIXQUARE is an independently operated, non-commercial project. It currently has no paid plan, subscription, or user account.
How do I create or join a room?
The host creates a room and shares the 6-digit code. Guests enter the code or use an invite link or QR code; the current flow assigns the Center role initially, and the role can be changed after joining.

2. Channel Routing

Which speaker role should I choose?
Each device can play a different channel by choosing Center, Left, Right, or Subwoofer.
What is Subwoofer mode for?
Subwoofer mode emphasizes low frequencies only. You can adjust the cutoff frequency in Settings.
Does MUSIXQUARE support 7.1 surround?
It is not exposed in the current user interface. An internal 7.1 channel-routing engine exists, but most user audio is stereo, so it is hidden from the product UI after usability review.

3. Connection

How many people can join?
A room supports up to 100 connected devices, including the host. The capacity is fixed; actual performance still depends on each device and network.
How can I keep outsiders from joining?
The host can enable an 8-digit numeric password in the Connection tab. When the password is enabled, new guests must enter both the 6-digit room code and the 8-digit password.
Do all devices have to be on the same Wi-Fi?
The same network is the most stable option, and file and system audio sharing is usually exchanged directly there. For remote participants or in large rooms, this data may route through Cloudflare. Quality can vary depending on the network, VPN, firewall, and browser policies.

4. Local File Mode

Who can add local files?
Only the host can add local files. Operator guests and regular guests cannot add files.
Does MUSIXQUARE preload the next track?
Yes. In local file playback, MUSIXQUARE can preload the next track to reduce waiting time during track changes. Remote preload is not supported.
Are shared files stored on a server?
Ordinary-room files are usually transferred directly on the same network. For remote participants or in large rooms, the sharing browser encrypts files before temporary Cloudflare R2 storage. MUSIXQUARE does not store the decryption key, and the objects are automatically deleted within an intended maximum of 24 hours. MUSIXQUARE does not access, analyze, or retain the content except as technically necessary to provide file sharing.
Can I upload video files directly?
No. Local File Mode rejects video files so every device uses the same audio playback path. For video, use YouTube watch-together mode.

5. YouTube Mode

Do channel routing or audio effects apply in YouTube mode?
No. YouTube mode uses the YouTube IFrame Player, so MUSIXQUARE's advanced audio effects and channel routing do not apply.
YouTube sync is not aligned. What should I do?
Try syncing again or check the network condition. YouTube IFrame performance can differ by device, so we are continuing to improve correction behavior.
YouTube works. Are Spotify, Apple Music, or Netflix supported?
Those services are not supported because of their service policies. If the host is on a PC, consider using System Audio Sharing for audio sources that can be shared by the browser.

6. System Audio Sharing

Where can I use system audio sharing?
System Audio Sharing is available in desktop Chromium-based browsers such as Chrome and Edge. The audio sources offered by the browser vary by operating system and by the selected tab, window, or screen. Mobile browsers and Safari are not currently supported.
How many devices can share system audio, and for how long?
System audio can be shared with up to four connected devices, including the host. If a fifth device joins, sharing ends automatically. Each sharing session also ends after two hours and can be started again if the room is back within the device limit.
Why does System Audio Sharing feel delayed compared with the host?
The host's audio needs time to be processed and transmitted. This mode is meant for muting the host's own speaker, syncing sound through the remaining participant devices, and applying audio effects there.

7. Other Issues

Sync is not perfectly aligned.
MUSIXQUARE supports precise sync, but device performance, browser behavior, network conditions, and Bluetooth latency can still create differences. Use manual sync adjustment when needed.
I cannot connect, or there is no sound.
Check the room code, make sure the host is still keeping the session open, and check browser mute or iOS silent mode. If the issue continues, restart the browser.
