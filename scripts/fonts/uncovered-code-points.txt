# Characters the app may show that no self-hosted face draws, in any of its
# font stacks. They fall to a device font, which the browser may pick by the
# page language, so they can look different between UI languages.
#
# scripts/check-app-font.mts holds this list to the exact gap, in every text
# stack of every UI, over every non-PUA character Pretendard drew, every
# character of the catalogs and index.html, the KS X 1001 repertoire and the
# visible text-presentation symbols of the punctuation, letterlike, arrow,
# math, technical, geometric, symbol, dingbat and CJK punctuation blocks: a
# new gap, or a listed character that gained a face or is no longer
# required, fails it. One U+XXXX per line in code point order; text after #
# is a comment (the character itself, or a dotted circle with a combining
# mark).
#
# Most are IPA letters, combining marks, sub- and superscripts, letterlike,
# math, technical and dingbat symbols outside the downloaded Inter subsets
# and the Noto CJK shards. U+202F (narrow no-break space, used in the French
# catalog) and U+2060 (word joiner) are invisible and left to the device font
# on purpose: the generator removes them from the CJK families.
# 1270 code points.
