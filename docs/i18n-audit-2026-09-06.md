## 원문 보호와 제품 계약

`src/i18n/ko.ts`와 `src/i18n/en.ts`는 기준 커밋과 바이트 단위로 동일하다.
두 앱 원문의 설정 도움말에 남은 예전 호스트·참여 버튼 인용은 원문 보존 요청에 따라 유지했다. 대상 언어의 인용은 현재 실제 번역 버튼에 맞췄다.

예외는 About의 `standin.caveat` 한 키다. 기존 원문의 “모든 Standard 방 공유는 2시간 후 종료”가 실제 동작과 달라 한국어·영어를 포함한 **42개 언어**에 사실 정정을 반영했다.
**원격 공유와 모든 Cloudflare(SFU) 중계 공유는 2시간 후 종료되며, 검증된 PRO LAN-direct 공유는 방 권한이 정상 작동하는 동안 계속할 수 있다.**
Standard LAN 공유 전체에 고정 2시간 제한을 새로 부과하지 않는다. 이는 기존 코드·회귀로 확인한 동작에 문구를 맞춘 것이다.
같은 정정은 `.workshop`의 landing·FAQ·Terms·Privacy 영문 4곳에도 적용했다. 이 4개는 위 사전 값 266개와 별도이며, 42개 About 정정은 About 52개 안에 포함된다.

보간 변수, HTML, 개행, 고정 수치·단위와 제품명, GLOBAL/LOCAL의 범위, 권한·보관·상품 약속을 보존했다.
CSS, 런타임 로직, 기능 정책은 변경하지 않았다. 근거와 원문 예외는 [원장의 `sourceProtection`·`structuralVerification`](./i18n-audit-2026-09-06.json)에 기록했다.

## 최종 레이아웃 판정

최종 보완한 4개 언어는 192개 화면 조합을 다시 측정했다. 아래 잔여 항목은 번역을 과도하게 줄이거나 CSS를 바꾸지 않고 유지한다. 2,016개 측정 완료가 모든 넘침의 해소를 뜻하지는 않는다.

- 타밀어 About CTA와 중국어 간체·번체의 미디어 설명은 자연스러운 짧은 문구로 교체했다. 4개 너비의 해당 12개 측정에서 잘림이 없다.
- 320px의 시스템 오디오 버튼은 텍스트 가용 폭이 약 28px이며, 한국어를 포함한 22개 언어가 버튼 높이를 넘는다. 기능명 의미를 유지한 추가 축약이 적절하지 않아 유지했다. 360px 이상에서는 해당 신호가 없다.
- 320px의 러시아어·우크라이나어·말라얄람어 초대 코드 문구는 두 줄로 배치되며 실제 clipping은 없다. 뜻을 보존했다.
- 타밀어 About, 중국어·스페인어 미디어 창, 말라얄람어 설정, 아랍어 RTL 화면을 표본 이미지로 확인했다. 모든 측정 조합을 수동 시각 검수했다고 주장하지 않는다.
