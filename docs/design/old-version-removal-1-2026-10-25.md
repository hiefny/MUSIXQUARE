## 배포·회복

**배포 대상.** 예상 target `app`, Developer API D1 `false`. 이 열차는 App 런타임 입력(`src`, `browser/classic-runtime`의 두
파일, `vite.config.ts`)과 가드·테스트만 바꾼다. bump는 SemVer와 SW 캐시 epoch를 함께 올리는 마지막 런타임 커밋이어야
한다(지금 `guard:sw-cache-version`이 v784 뒤의 런타임 변경 38개 파일을 나열하며 FAIL). 업데이트 창이 뜨는 배포다.

**병렬 열차와의 합침.** `git merge-tree`로 미리 보면 `agent/phase5-5a`(9.0.12 bump 뒤)와는
`browser/classic-runtime/admin.ts` 한 곳이 충돌한다(5A bump의 `ADMIN_SCRIPT_VERSION` 줄 옆에서 이 열차가 `window` 전역 한 줄을
지움). registry, `qa-domains.md`, room-authority-boundaries 스크립트와 테스트, `file-prepare-pause.test.ts`, `types/index.ts`,
`vite.config.ts`는 자동으로 합쳐지지만 가드 숫자(room-authority 직접 읽기·쓰기 합, dead-exports, resource-ownership)는 합친 뒤
다시 돌려야 한다. `agent/forced-update`와는 지금 텍스트 충돌이 없다(겹치는 파일은 `admin.ts`, registry, `ui/setup.ts`).
나중에 합치는 쪽이 전체 단위, 가드, 빌드를 다시 돌린다.

**되돌리기.** 코드 되돌리기가 기본이다. revert도 더 높은 SemVer와 캐시 epoch로 다시 배포한다
([hotfix-procedure.md](../hotfix-procedure.md)의 Rollback). 급할 때의 Cloudflare App 버전 되돌리기는 같은 PRO 입장 정책
계약 표지를 가진 이전 빌드로 할 수 있다. 되돌리면 지운 허용과 대체가 돌아올 뿐이고, 이 열차는 저장 데이터 모양, D1,
비밀, 바인딩을 바꾸지 않는다. 되돌린 빌드와 이 열차 빌드가 한 방에서 만나는 경우는 위 혼합 버전 표와 같다.

## 확인하지 않은 것

- 실제 기기, iOS·WebKit, 운영 Cloudflare 전송 경로, 브라우저의 PRO 방을 이 열차 코드로 돌리지 않았다.
- 실제 옛 빌드(8.3.16~9.0.11)와 짝지은 혼합 방을 돌리지 않았다. 현재 클라이언트와의 호환은 9.0.10(`2038b51f`)·9.0.11
  (`244aca48`)과 이 열차의 송신·검증 코드를 읽은 것, 단위 테스트, 리뷰어가 9.0.11 코드에 이 빌드의 프레임을 넣어 본 실험에
  기댄다. 2.2의 나빠짐(약 200 ms 일찍 시작, 데모 못 따라감, 3초 먼저 들림, 느린 트랙 전환, 늦은 펄스 따라잡기, 8.11.23
  상대와의 늦은 닫힘)은 조사와 코드에서 끌어낸 것이고 재지 않았다.
- 로컬 게스트 9명 이상인 방, 늦게 온 아홉 번째 로컬 게스트(R6), 9.0.10·9.0.11 방장의 효과 변경을 이 열차 게스트로 받는 것(R4)을
  실제 브라우저로 보지 않았다.
- R4가 바꾼 청크 배치(`playlist.ts`, system-capture, sync, preload가 진입 청크로 감)의 시작 순서는 critical E2E와 랩이
  지나갔을 뿐 실제 기기 첫 로딩으로 보지 않았다.
- PeerJS 대체 경로의 운영자 업로드에서 FINISH가 청크 뒤에 남는다는 것은 단일 순서 채널에서 끌어낸 것이다(R1).
- R8은 따로 두 렌즈 리뷰를 받지 못했다. 8.11.23 상대와의 보조 경로 끊김은 단위와 두 연결 통합 테스트로만 고정했다.
- 브라우저에서 일반방 Peer가 PRO 세션까지 살아남는지는 코드로만 읽었다. 남더라도 이제 닫힌다(R5).
- PR CI, Codex, exact-main CI, 릴리스 smoke, 운영 배포. 이 로컬 결과는 exact-main-SHA 후보를 대신하지 않는다.

운영 데이터나 서비스에 장애를 주입하는 검사는 하지 않았다.
