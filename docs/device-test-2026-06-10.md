## 세트 A — 로컬 기본 (데스크톱 호스트 + 폰 게스트 1~2)

### A1. ★ EXT-1 — 중복 파일명 점프 (오늘 마지막 픽스)
1. 같은 음악 파일을 **두 번** 추가 + 다른 곡 하나: 순서 = `A(0), B(1), A사본(2)`
2. **B(1번) 재생** → 게스트에 "미리 받기 완료" 토스트 뜰 때까지 ~10초 대기 (다음 곡 A사본이 프리로드됨)
3. 재생목록에서 **0번 A를 클릭** (프리로드된 2번과 같은 이름, 다른 위치)
- ✅ PASS: 게스트가 5초 내 재생
- ❌ FAIL: 게스트 로더가 "다운로드 마무리 중"류에 12초+ 정체

### A2. ★ SA-09 — 방 일시정지 중 게스트 잠금화면 resume 차단 (어제 픽스)
1. 로컬 곡 재생 → 게스트 폰 잠금
2. **호스트가 ⏸** (방 전체 정지)
3. 게스트 잠금화면에서 ▶ 탭
- ✅ PASS: 게스트 혼자 재생되지 **않음**. 호스트 ▶ 시 다 같이 재개
4. (반대 확인) 호스트 재생 중 → 게스트 잠금화면 ⏸ → 다시 ▶
- ✅ PASS: 게스트 재개 + 1~2초 내 위치 자동 싱크

### A3. ★ CONN-1 — 희소 슬롯에서 최대 기기 수 축소 (폰 2대)
1. 연결탭 최대 기기 4로 설정 → 게스트 a 입장(슬롯1), 게스트 b 입장(슬롯2)
2. **a 퇴장** (b만 남음, 슬롯2 = 높은 슬롯)
3. 호스트 연결탭에서 최대 기기 **4→1**로 축소
- ✅ PASS: b 연결 유지(강퇴 없음), 재생 지속, 기기 목록 정상
- ❌ FAIL: b가 "내보내짐" 화면

### A4. ROLE-2/3 — OP 변경 시 호스트 UI 동기화

2. ✅ 호스트 설정탭 서라운드 칩도 ON으로 표시 / 호스트가 칩 OFF→ON 클릭 시 정상 반응(무반응 없음)
3. 이펙트 하나 건드려둔 상태에서 **새 게스트 입장**
4. ✅ 새 게스트에 "방장이 설정을 변경했어요" 허위 토스트 **없음**
5. (보너스) OP가 리버브 슬라이더 드래그하는 도중 호스트가 권한 회수 → ✅ 몇 초 내 게스트 이펙트가 방 상태로 복귀
